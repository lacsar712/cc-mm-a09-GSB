# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时为报警；达到检查员设定的危急线（默认 1.5%，须高于 1%）时为危急。服务端通过网页套接字把新记录推到已经打开的页面。危急记录集中显示在顶栏「危急专板」。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可保存危急线 |
| viewer | view123456 | 只能看（含危急专板），不能改危急线 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. gasman 在「危急专板」把危急线设成 1.5：上报 1.6 的测点状态为危急并进入危急专板；上报 1.2 的测点仍是报警、不进专板。
5. 改危急线只影响新上报，历史行状态原文不变；viewer 能看危急专板，但不能保存危急线（输入框禁用，接口返回 403）。
